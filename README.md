# Watch-AR-Try-On

Website thương mại điện tử trưng bày đồng hồ + AR Watch Try-On (thử đồng hồ qua camera).

Hiện tại repo chứa **MVP frontend** (ReactJS + Three.js + MediaPipe Hands) demo tính năng AR Try-On.

## Chạy nhanh

```bash
cd frontend
npm install
npm run dev
```

Mở http://localhost:5173 và bấm **"Thử đồng hồ AR"**.

Chi tiết: xem [`frontend/README.md`](./frontend/README.md) và spec đầy đủ trong [`PROMPT_CLAUDE_CODE_WATCH_AR.md`](./PROMPT_CLAUDE_CODE_WATCH_AR.md).
